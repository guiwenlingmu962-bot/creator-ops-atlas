# CreatorOps Atlas

米国・日本の合法な成人向けクリエイター事業者に向けた、非露骨・業務運営特化の静的サイトです。画像生成、成人コンテンツ配信、投稿、決済、会員登録、実顧客データ保存は行いません。

## ローカル表示

リポジトリのルートで実行します。

```powershell
python -m http.server 8010 --directory sites/creator_ops_atlas
```

ブラウザで `http://localhost:8010` を開きます。英語が初期表示で、日本語切替と地域フィルターが動作します。

## 公開前に必ず変更する項目

1. 運営者情報、対象国の表示義務、問い合わせ先を専門家と確認する。
2. 各プラットフォームのリンク・規約・提供地域を再確認する。
3. FANZA/DMMアフィリエイト審査承認後のみ成果報酬リンクを追加する。
4. 成果報酬リンクの直前に、報酬を受け取る旨を明記する。
5. 分析・広告・フォームを追加する場合は、プライバシー文書と同意設計を更新する。

## 運用禁止事項

- 露骨な画像、音声、動画、サンプル、ユーザー投稿を置かない。
- 未成年、年齢不明、同意不明、無断転載、ディープフェイクを扱わない。
- 出会い、エスコート、性的サービスを仲介しない。
- PayPalで成人向けデジタル商品や会員購読を決済しない。
- 本人確認書類、出演者記録、顧客住所、パスワード、APIキーを受け取らない。
- 規約違反スクレイピング、スパム、大量自動送信をしない。

## 収益化順序

1. 人間確認付き自動化相談への送客。
2. 小規模受託を30,000〜70,000円で納品。
3. 公開サイトをFANZA/DMMアフィリエイトへ申請。
4. 承認後、明示付き成果報酬リンクを追加。
5. 十分な編集実績ができてから、スポンサー枠を明確に分離して販売。

相談導線は既存のFreelancerプロフィールを使用します。サイト自身はカード情報・支払情報・個人情報を受け取りません。

法律・規約・料金は変更されます。サイト内の日付を基準にせず、公開・提携・受注の直前に公式情報を再確認してください。
